# AI Vlog App 项目说明

## 项目背景
本项目是配套 ESP32-S3-EYE 硬件参加 OpenVela 智能硬件大赛的手机 App（Flutter，仅 Android）。

**核心定位**：接收设备/电脑端生成好的 Vlog 视频，进行管理、播放、保存到相册。  
**视频生成**：已全部在硬件 + 电脑端完成，App 只负责接收和播放。

## 工程信息

- **工程位置**：本文件夹内 `ai_vlog_app\`（自包含，可独立构建；旧位置 `C:\Users\MI\Desktop\selfie_scorer\ai_vlog_app` 已不再依赖）
- **技术栈**：Flutter 3.35.7 / Dart 3.9.2（Android only）
- **安装包**：`AI-Vlog.apk`（48.4MB，纯 HTTP 版，位于本文件夹根目录）
- **最后更新**：2026-09-17

## 系统架构

### 数据流向
```
ESP32-S3-EYE 拍摄 BMP 
    ↓
上传电脑后端
    ↓
电脑异步生成 MP4
    ↑ (HTTP 拉取)
手机 App 填电脑 IP，自动/手动下载视频
```

### 传输协议
- **纯 HTTP 通信**（蓝牙方案已废弃删除）
- App 填入电脑后端 IP → 拉取视频列表 → 下载 MP4 文件

### 接口约定
- **GET /list**：返回视频列表  
  ```json
  [{"name": "xxx.mp4", "size": 123456, "title": "标题", "url": "完整下载URL"}]
  ```
- **GET /download?name=xxx.mp4**：返回视频文件流（需 Bearer Token 认证）

## 功能模块

### 1. Vlog 库（首页）
- **文件**：`lib/pages/vlog_library_page.dart`
- **功能**：
  - 列出已接收/导入的所有视频
  - 点击播放视频
  - 删除本地视频
  - 手动导入本地 MP4 文件
- **存储**：使用 SharedPreferences 持久化视频记录

### 2. 设备页
- **文件**：`lib/pages/device_page.dart`
- **功能**：
  - 输入电脑后端 IP 地址连接
  - 显示可接收的视频列表
  - **自动接收模式**（默认开启）：
    - 每 10 秒轮询 /list 接口
    - 发现新视频自动下载到本地
    - 后台静默下载，完成后通知
  - **手动下载 / 重新下载**：每个视频右侧都有按钮——未下载显示"下载"图标，已下载显示"重新下载"（刷新图标），随时可再次拉取
  - 下载进度实时显示
  - 下载落点由"设置页 → 下载存放位置"决定
- **智能判重**：通过文件名和标题避免重复下载（仅影响图标样式与自动接收，不再阻止手动下载）

### 3. 播放器
- **文件**：`lib/pages/player_page.dart`
- **功能**：
  - 全屏播放视频（循环播放）
  - 点击暂停/继续
  - 保存到相册（Gal 库，自动创建"AI Vlog"相册）

### 4. 设置页
- **文件**：`lib/pages/settings_page.dart`
- **功能**：
  - **下载存放位置**（三选一，`RadioGroup` 单选）：
    - **应用内部目录**（默认，推荐）：最稳定，文件管理器不可见，卸载 App 后清除
    - **应用外部目录**：`Android/data/包名/files`，文件管理器可见，卸载后清除
    - **自定义文件夹**：弹系统文件夹选择器；选中后先做写入测试，不可写会提示更换（受 Android 分区存储限制）
  - 关于 App、版本信息
- **落点解析与兜底**：由 `SettingsStore.resolveDownloadDir()` 统一解析，任何位置解析/写入失败都自动回退到应用内部目录，保证下载永远有落点

### 5. 核心服务

#### DeviceClient（设备通信）
- **文件**：`lib/services/device_client.dart`
- **职责**：
  - HTTP 请求封装（基于 Dio）
  - 视频列表拉取
  - 视频文件下载（带进度回调）
  - 错误信息友好化处理
  - 跳过内网自签名证书校验

#### VlogStore（本地存储）
- **文件**：`lib/services/vlog_store.dart`
- **职责**：
  - 视频记录的增删查改
  - SharedPreferences 持久化
  - 按时间倒序排列

#### SettingsStore（App 设置）
- **文件**：`lib/services/settings_store.dart`
- **职责**：
  - 下载存放位置模式（internal / external / custom）与自定义路径的持久化
  - `resolveDownloadDir()`：按当前设置解析下载目录，失败自动回退内部目录
  - `testWritable()`：目录写入测试（建临时文件再删），用于校验自定义文件夹是否可写

## 技术要点

### 自动接收逻辑
1. 用户开启"自动接收"开关（默认开启）
2. App 每 10 秒调用 /list 拉取最新列表
3. 对比本地已有视频（通过文件名和标题判重）
4. 发现新视频自动后台下载
5. 下载完成后弹通知 + 刷新 Vlog 库

### 判重机制
- 提取本地所有视频的原始文件名（去掉时间戳前缀）
- 同时记录所有标题
- 远程视频如果文件名或标题已存在，标记为"已在本地"

### 错误处理
- 连接超时：提示检查 IP 和网络
- 连接失败：提示确认同一网络
- 下载失败：静默（自动接收），或弹错误信息（手动下载）
- 轮询失败：静默（不打断用户）

## 注意事项

1. **不要升级 Flutter**：当前版本稳定，升级可能引入新问题
2. **JDK 版本固定**：必须使用 JDK 17，不要用系统默认 Java
3. **Bearer Token 硬编码**：当前 Token 硬编码在 DeviceClient，生产环境需改为配置项
4. **内网证书跳过**：开发环境跳过 HTTPS 证书校验，生产环境需评估安全风险
5. **存储位置**：默认存应用内部私有目录（卸载 App 会丢失）；可在设置页改为应用外部目录或自定义文件夹。自定义文件夹受 Android 分区存储限制，部分系统目录不可写，选择时会自动做写入测试
6. **播放依赖绝对路径**：Vlog 库记录的是下载时的绝对路径。若下载后手动移动文件，或切换存储位置后原文件被清理，播放会失败（库页面会标注"文件已删除"）
