### ✅ 真机构建成功（最终可用配置 + 踩坑记录）
**APK 构建成功**：build/app/outputs/flutter-apk/app-debug.apk（328MB，含 ffmpeg 全套原生库）。

最终可用的版本组合：
- Flutter 3.35.7 + Dart 3.9.2（从 3.47.4 降版，因 3.47 要 AGP9 与 ffmpeg 冲突）
- **ffmpeg_kit_flutter_new 4.6.2**（关键！旧的 1.6.1 靠 build.bat 从 GitHub 下 aar 已 404 失效；4.6.2 改用 Maven 依赖 com.antonkarpenko:ffmpeg-kit-full-gpl:2.2.1，稳定）
- Gradle 8.12 + **AGP 8.7.2 + Kotlin 1.9.24**（KGP 有警告要求≥2.1 但能构建；provider 报错主因其实是 SDK36 缺失）
- JDK 17（winget 装 Microsoft.OpenJDK.17，flutter config --jdk-dir 指定；系统默认 Java25 与 Gradle8 不兼容）
- compileSdk=36 / minSdk=24 / targetSdk=34 / ndkVersion=27.0.12077973（全写死，不读 flutter.xxx provider）
- **android-36 platform 原缺 android.jar**，用 cmdline-tools 的 sdkmanager 正规安装补齐（关键！这是 MissingValueException 的真正根因）
- CMake 3.22.1 构建时自动装

踩坑教训：`Cannot query the value of this provider` 这个模糊报错的真正根因是 **compileSdk 对应的 SDK Platform 不完整（缺 android.jar）**，写死 compileSdk 后才暴露出可读的 "require SDK 36 / find target android-36 failed" 提示。
