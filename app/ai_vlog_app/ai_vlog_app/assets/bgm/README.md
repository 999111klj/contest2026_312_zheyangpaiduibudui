# BGM 素材说明

video_service 会按大模型给的 `bgm_mood` 匹配以下文件名之一（放在本目录）：

- `upbeat.mp3` —— 轻快/明亮/活力（关键词：快、明、活）
- `gentle.mp3` —— 温柔/怀旧/温暖/宁静（关键词：柔、怀、暖、静、宁）※默认
- `epic.mp3`  —— 燃/激昂/励志（关键词：燃、激、励）

## 重要
- 这些是 **二进制音频**，代码无法凭空生成，需你放入 **无版权 / 自制** 的 mp3。
- **缺失也不影响出片**：找不到对应 BGM 时，video_service 自动降级为"无声成片"，链路照常跑通。
- 演示前放 3 首无版权情绪音乐进来即可（文件名严格按上面命名）。
- 无版权音乐来源建议：YouTube Audio Library、Pixabay Music、Free Music Archive 等（注意各站授权条款）。
